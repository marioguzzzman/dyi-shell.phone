# Enclosure — 3D-printable shell

The shell that houses the electronics. It's not just a case: the bone-conduction
transducer is mounted against it, so the shell itself vibrates and becomes the speaker.

## Files
- `hollowShell_full_new.3mf` — 3MF model (keeps print settings; open in a slicer like PrusaSlicer / Bambu Studio)
- `hollowShell_full.obj` — plain mesh (open in any 3D tool)
